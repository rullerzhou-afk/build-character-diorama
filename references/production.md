# 美术、素材与空间

## 参考职责与技术路线

为轮廓比例、线条、代表色、材质、密度和镜头分别记录“保留／调整／避免”。一张图可以只负责形体，另一张只负责表面。身份参考、画风参考、实际场景各有职责，标清优先级；不能把喜欢某一部分理解为整图照搬。自主选型写明依据，不冒充用户认可。

| 需求 | 表现起点 | 检查代价 |
| --- | --- | --- |
| 多角度轮廓、遮挡、接触 | 几何或贴图体块 | 基本体和粗材质可能达不到概念质感 |
| 固定主视角、丰富插画细节 | 固定或受限朝向画片 | 侧薄、露背、透视、阴影不匹配 |
| 木石布料、图案、平面局部 | 几何加贴图 | 显示尺度、接缝、拉伸和烘焙光 |
| 植物和远景 | 画片与少量几何混合 | 根部、深度、遮挡和镜头变化 |
| 角色局部运动 | 分层图像、关键姿态或几何关节 | 结构完整、根部遮盖、跨状态漂移 |

家具、植物和接触道具可以各选路线。先完成角色与代表性物件的实际网页小样，在目标页面大小和镜头中看表面、轮廓、阴影和有限旋转。质感不够先改素材或表现方式，不继续用低细节占位扩大全场景。整张概念图不能冒充可观察空间。

重要物件仍停留在“更精细一些”而缺少具体做法时，用 [object-craft.md](object-craft.md) 的工艺卡明确轮廓、结构、表面与观察距离；已有清楚方案的小修无需补卡。

## 从概念到素材

只从本任务授权素材取材，使用执行环境允许的图像工具：

1. 明确局部用途、允许视角、屏幕尺寸和独立遮挡需求。
2. 裁取或重生成目标，校正不需要的透视，补全被遮挡结构。
3. 清理背景、白边和不需要的烘焙阴影，保留内部透明与完整轮廓。
4. 统一源画布、方向、物理尺度与连接点，保留源图和可信版本。
5. 回到实际场景核对缩小清晰度、边缘、颜色、接触与阴影。

身份与画风分开锁定；统一画法不意味着改掉代表色。完整部件生产见 motion.md。

### 从生成工具取得可对齐的部件

先保留一张可信的定稿底图及其画布、尺度和连接点。需要拆肢体时，可选部件稍离开身体的姿态，减少遮挡，不要求所有角色都用同一种站姿。

在这张定稿上编辑，每次明确要移除、补全和保留的区域。例如先去掉一条手臂并补齐身后的身体，再补出完整肩头与手臂，另做需要的握持姿态；未改区域的脸、体型与颜色作为对照。

“同一画布上编辑”不保证输出像素尺寸或位置完全不变。收到结果后先核对实际尺寸、轮廓范围和稳定部位，再恢复共同画布与锚点；整体缩放或平移可以统一校正，局部比例已改变则回到生成步骤，不能靠拉伸肢体硬对齐。裁切时保留到源画布的偏移。

同姿态的局部编辑只取所需区域，用适合画风的蒙版合回定稿，未改区域保留原像素。将部件按静止姿态复合，用叠图或差值检查非预期变化；静止与动作沿用同一组稳定部件。蒙版不必一律羽化；换姿或换光后的结果按新的可信基准检查，不强求与旧图逐像素相同。

在浅、深背景和实际显示尺寸下检查颜色、透明边与关节连接。区分底色污染和应保留的毛发等半透明细节，按工具能力加工；回到场景跑部件的预计活动范围，不能只对齐静止姿势。切口与遮挡补片的判断见 [motion.md](motion.md)。

共同的工具、完整提示词、参考职责与加工步骤可按批记录，单项有差异时补记。每项运行资产能定位文件、来源和版本；拆分部件另保留尺寸、alpha、源画布偏移与锚点，用途、允许视角和限制按实际需要补充。程序几何与材质记录制作方法和必要参数，不为每个重复网格另填清单。项目不依赖工具的临时输出目录。

生成素材较多时，在第一批接入就按 [runtime-checks.md](runtime-checks.md) 检查加载体积与显示尺寸，保留原图，另导出运行版本。

## 基础空间与接入

已有底稿先在页面验收，判断缺的是结构还是精细资产。新灰盒只需主要体块、路径和接触面；净空不成立时先修布局。

- 角色、道具、触发区的尺寸与锚点来自同一来源。
- 检查默认与极限镜头、竖屏、完整运动扫过区域，不只起点终点。
- 独立角色与植物画片默认朝向当前相机的水平投影，只绕竖轴转向，保持竖直；以脚底或根部为锚点，转向不能带来位移。墙画、窗景等固定画片可保留朝向，但须说明构图依据并验收全部允许视角。木纹等附着在实体表面的纹理随实体，不做画片转向。
- 相机拖动、键盘、自动取景和 resize 后，在绘制前更新画片朝向；双面材质只决定背面是否可见，不能代替转向。父级有变换时转换到正确的本地坐标，附属部件与手臂连接跟随同一转向，持物接触点仍遵守场景约束。
- 透明排序、深度写入、alpha 阈值分别诊断，不能靠永久置顶破坏真实遮挡。
- 源图预览正常而场景缩小时出现亮暗描边，先查透明像素颜色、缩小过滤与预乘 alpha 链路是否一致，再按实际采样约定决定是否扩色或重新抠图。
- 背景层与附着物漂移时，先查父级、坐标和相机关系。
- 家具要有厚度、连接、支撑和尺度。角色过小或被框切断时修布局和镜头，不用文案弥补。

## 光照诊断

锁定同一镜头，一次比较一个问题层：

| 现象 | 优先检查 |
| --- | --- |
| 发灰、缺方向 | 环境光与主光比例、曝光、颜色空间、贴图烘焙光 |
| 灯亮而周围不亮 | 发光材质只让自身亮；是否有照向表面的光源或设计的局部效果 |
| 舞台外出现大片叠影 | 光源位置、照射范围或锥角、地面接收阴影的范围，以及多个光源的投影叠加 |
| 插画与环境脱节 | 无光照与受光材质混用、底色、阴影软硬和方向 |
| 阳光不显著 | 真实受光面、窗框投影、方向、阴影对比，不只提高总亮度 |
| 夜景发黑或像白天 | 角色画片单独的亮度响应、局部光、前后景关系 |
| 材质被冲淡 | 重复颜色变换、曝光、材质乘色、过强补光 |

有局部灯时，在固定镜头和环境光下单独切换该灯，分别比较灯芯外观与附近受光面的变化。再查看整页、默认与边界镜头，确认光和阴影没有延伸到不合适的区域；只看灯旁特写会漏掉大面积地面上的投影。先调整光源位置、范围、锥角和阴影接收范围，再调整强度，不用总曝光掩盖局部问题。

夜间主要交互物件必须仍可辨认。需要时使用受控补光或材质响应，保留轮廓、身份色和夜间层次，再复查是否冲淡了其他表面。

可用受控的无光照或混合表现，但全场景遵守同一美术逻辑。无昼夜需求不必新增。每次以实际角色和页面复查，不能只看材质球。

有日夜联动需求时，按 [day-night.md](day-night.md) 制作各时段的环境、角色、材质和局部灯光，并接入同一时间状态；本节用于定位其中的照明问题。
